# Drawloom app icon

`Drawloom.icon` is the editable Icon Composer source created from the existing
[Drawloom vector logo](../../../../publishing/site/public/artwork/synaptic-shuttle/logo.svg).
Its bundled SVG is an import of that artwork, not a second logo design.
`Drawloom-preview.png` is the default 1024-pixel rendering exported by Icon
Composer for review.

The native application still uses the existing configured icon assets. Compiling
and wiring the new Icon Composer asset and compatibility fallback into the app
bundle remains part of the pre-distribution work; saving this source does not
prove installed Dock/Finder rendering or packaging readiness.
