# Synaptic Shuttle artwork

Selected for the Drawloom product landing page on 2026-09-12. These are reusable,
text-free exports rather than crops of the interface mockup.

- `hero.png`: luminous copper and violet knowledge threads crossing a dark field,
  composed with quiet space for the landing-page headline. Generated at 1672×941.
- `decision-map.png`: an abstract connected reasoning map in the same visual
  language. Generated at 1672×941.
- `decision-map-transparent.png`: the same selected map, with its generated
  off-white field removed for reusable composition over the site surface. The
  colour-key post-process preserves the violet, copper and graphite network.
- `logo.png`: the selected shuttle-and-synapse mark, keyed to transparency and
  exported at 512×512.
- `logo.svg`: the maintained vector reconstruction of that selected mark. It
  preserves the transparent field, bone-white brain and shuttle structure, and
  the copper/violet woven paths in a responsive 512×512 view box. The PNG stays
  beside it as the selected visual source and provenance reference.

The source visual direction combines a loom shuttle, synaptic branching, human
cognition and knowledge fabric. The local generation masters are retained under
`/Users/afifim/.codex/visualizations/2026/09/12/01a09359-6fc8-7112-91e4-fe7321796974/drawloom-brand-backgrounds/`.
Their inclusion here records selection for this implementation, not permission
to publish or deploy the resulting site.
