# Journal font

Libre Caslon Display Regular is self-hosted for consistent display typography.
It was selected by comparing the actual example heading against the approved
journal mockup, rather than assuming a platform serif matches its proportions.

Source: https://github.com/google/fonts/tree/main/ofl/librecaslondisplay
Downloaded 2026-09-05. The original font is unmodified; its SIL Open Font License
is included in `OFL-LibreCaslonDisplay.txt`. Reading prose uses the system Times
family; navigation and small labels use the system Arial/Helvetica family.

These are static licensed design assets, not JavaScript dependencies. Fonts are
served locally, with no third-party font request during reading.
