## Task 1: private video consumer

Read the retained inventory and existing media inspection/validation code.
Create a private retained proof consuming the public candidate runner through an
explicit caller-selected public checkout. Do not copy/fork the contract or promote
spike imports into supported packages. Plain JavaScript composition with runtime
schema validation is acceptable for this unreleased cross-checkout experiment.

Assess an existing local master using plugin-owned, independently specified
technical criteria: video/audio streams, delivery geometry and cadence, decoded
integrity and duration/alignment where the retained facts support expectations.
Unknown business/clinical quality must stay unknown. Verify source hashes before
and after and execute zero generation/target calls. Do not infer desired output
from the output being scored. Include deliberately wrong requirements or selected
existing unsuitable material as negative cases; do not alter production samples.
Keep resolution source-bound and reject unpermitted references before inspection.
Persist attributable results/feedback locally and verify reloading them.

Write failing tests first, use actual inspection paths and real local SDK calls,
record timing/memory/read characteristics honestly, and run private checks.
No new vendor installation should be needed: load the already pinned public proof
runner from the selected checkout. Keep source/report paths out of public outputs.
