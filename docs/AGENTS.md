# Documentation agent guide

This guide applies under `docs/`.

- Write for a reader who did not participate in the originating conversation.
- Link to an authoritative fact instead of copying it into multiple documents.
- Keep ADRs immutable after acceptance except for corrections and status links.
- Supersede a decision with a new ADR; do not silently rewrite history.
- Give plans a bounded outcome, verification steps, and an explicit lifecycle.
- Remove or archive completed plans according to the convention in
  `docs/plans/README.md`.
- Put generated material in `docs/reference/generated/` when that directory is
  introduced; never hand-edit generated output.
