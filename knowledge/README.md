# Knowledge

This directory is the provenance-bearing knowledge bundle for Drawloom. It
follows OKF 0.2 plus the stricter local profile in `AGENTS.md`.

Use it for sources, assumptions, evidence, computations, and other records whose
origin and lifecycle matter. Architecture decisions remain authoritative in
`docs/adr/`; knowledge records may link to them but must not copy them.

Start at [`index.md`](index.md).
