# Knowledge, memory and context references

The [survey](../../docs/reference/knowledge-memory-survey/README.md) owns the
source inventory, pinned implementation reports, lifecycle comparisons,
Archify diagrams, vocabulary research and verification limits.

It compares retention, derivation, correction, retrieval and context assembly
across public memory systems, harnesses and workbenches. Research code and
benchmarks are identified separately from product implementations. Current
Letta Code is distinguished from the archived Python server.

These are source-inspected findings, not executed upstream conformance or
benchmark results. Diagram checks validate the retained artifacts only.
Candidate lessons do not amend approved Drawloom contracts. Refresh relevant
source evidence before making a new decision; do not substitute retrieval
scores for confidence, scope labels for entitlements, or capture checkpoints
for completed knowledge maintenance.

No private clinic OKF records or other proprietary material are included.
