# Drawloom visual design system

## Overview

Drawloom has not yet selected a visual identity. Visual tokens and component
rules remain deliberately omitted until interface work provides evidence for
them; do not invent defaults merely to fill this document.

When visual decisions are made, record their tokens and guidance here using
Google's [design.md specification](https://github.com/google-labs-code/design.md/blob/main/SPEC.md).
The specification accepts CSS colour formats including OKLCH; Drawloom has not
yet chosen a preferred colour notation.
